INSTALL FOCUS LENS IN CHROME

This release is an unpacked extension. Chrome Developer mode is required.

1. Extract this ZIP to a folder you will keep.
2. Open chrome://extensions in Chrome.
3. Turn on Developer mode.
4. Select Load unpacked.
5. Choose this extracted folder. It contains manifest.json.
6. Pin Focus Lens, open a regular web page, then select its toolbar button.

To update it, replace the folder contents and select Reload on
chrome://extensions. To remove Focus Lens and its settings, select Remove.
